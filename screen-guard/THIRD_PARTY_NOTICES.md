## Gender classification TensorFlow Lite model

The file `model_lite_gender_q.tflite` is downloaded at build time from:

- Project: https://github.com/shubham0204/Age-Gender_Estimation_TF-Android
- Repository license: MIT
- Model path: `app/src/main/assets/model_lite_gender_q.tflite`

The app uses the model only as an experimental visual-presentation classifier. The original model author describes output index 0 as Male and output index 1 as Female. This is not a reliable determination of actual gender.
